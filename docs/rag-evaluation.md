# RAG检索回归评测

评测日期：2026-10-18。固定问题见tests/rag_cases.json，运行node tests/rag_evaluation.cjs。该脚本启动独立无API密钥服务，只评测检索与拒答，不测大模型生成质量，也不消耗付费API。

| 指标 | 改进前 | 改进后 |
| --- | --- | --- |
| 27个课程问题的预期文件命中 | 24/27 | 27/27 |
| 3个无证据问题拒答 | 3/3 | 3/3 |
| 返回来源跨课程 | 0 | 0 |

命中定义：实际返回的sources中至少一个path与该问题预先标注的预期资料文件一致。不是回答正确率，也不是严格Top-1准确率。脚本记录每题耗时，但本机无模型结果不代表公网模型延迟。

发现的问题：中文口语问句的冗余短语降低关键词覆盖率；数组边界与递归调用栈的讲解不够集中。对应改进为补充通用问句归一化，并在课程资料中加入实际边界行为和调用栈说明，没有写死问题到答案的映射。

本组问题参与了调试，因此属于回归集，不能宣称为独立测试集或100%通用准确率。提交比赛前，应由队友另拟至少20条未参与开发的问题，并人工检查答案、引用相关性、拒答合理性；保存失败样例，不只展示成功案例。对AI生成内容另外检查标准答案一致性和是否编造来源。

当前技术是按课程过滤、Markdown切块、关键词加权、覆盖率门槛和相对分数截断。没有向量数据库和Embedding，不应把它描述成向量RAG。后续是否引入混合检索，应由独立评测中的真实漏检决定。
