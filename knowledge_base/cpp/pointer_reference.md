# C++ 指针与引用

课程：C++
知识点：指针与引用

## 指针

指针是保存内存地址的变量。指针可以为空，可以在程序运行过程中改变指向，也可以通过解引用运算符访问其指向的对象。

## 引用

引用是已有对象的别名。引用在声明时必须初始化，初始化后通常不能改为引用其他对象。

## 主要区别

1. 指针可以为空，引用通常不能为空。
2. 指针可以改变指向，引用初始化后不能重新绑定。
3. 指针需要使用星号解引用，引用可以像普通变量一样使用。
4. 指针本身占用存储空间，引用通常作为已有对象的别名使用。

## 示例

```cpp
int value = 10;
int* pointer = &value;
int& reference = value;

*pointer = 20;
reference = 30;
```
