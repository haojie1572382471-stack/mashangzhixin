# 条件与循环、函数

课程：C++
知识点：变量与数据类型、运算符与表达式、条件与循环、函数

来源：码上知新课程知识库

## 核心概念：条件与循环、函数、值传递和引用传递

bool 保存 true 或 false。const 对象初始化后不能通过该变量再次赋值。auto 根据初始化表达式推导类型，例如 auto x=3.5 推导为 double。
整数除法 7/2 的结果是 3，乘法优先于加法，因此 2+3*4 为 14。内置逻辑与 && 和逻辑或 || 支持短路求值，短路时右操作数不执行。
if 根据条件选择分支。for 依次执行初始化、条件检查、循环体、更新表达式。continue 跳过本轮剩余语句，for 仍会执行更新表达式；break 退出最内层循环或 switch。
switch 的 case 默认允许贯穿，若不需要贯穿应使用 break；有意贯穿可写 [[fallthrough]] 表达意图。
函数值传递复制实参，引用传递可以修改实参。普通函数不能仅凭返回类型不同构成重载。

条件与循环控制执行路径，函数把重复步骤封装为独立操作。if/else 适合区间判断，switch 适合离散整型或枚举值的多分支；循环设计先写清初始值、继续条件和每轮变化，再考虑终止性。函数定义要明确输入、输出和副作用：只读小对象可值传递，较大对象常用 const 引用减少复制，需要修改调用者数据时才用非 const 引用。局部变量只在作用域和生命周期内有效，不能返回局部变量的引用或地址。

## 代码示例

下面示例使用 C++17，可独立保存为 .cpp 文件编译运行。assert 检查关键结果；阅读时先预测输出状态，再运行验证。

```cpp
#include <cassert>
void by_value(int x) { x = 9; }
void by_reference(int& x) { x = 9; }
int main() {
    int a = 1;
    by_value(a);
    assert(a == 1);
    by_reference(a);
    assert(a == 9);
    int sum = 0;
    for (int i = 0; i < 4; ++i) {
        if (i == 2) continue;
        sum += i;
    }
    assert(sum == 4); // 0 + 1 + 3
    int x = 0;
    bool result = false && (++x > 0);
    assert(!result && x == 0);
}
```

## 常见错误

把 = 当成 ==；误以为整数除法自动产生浮点结果；把 continue 当成 break；忘记 switch 的贯穿行为；以为值参数的修改会影响原变量。
不要用存在未定义行为的表达式练习运算符优先级。需要小数结果时，可先将除数或被除数转换为 double。

调试条件与循环时，可用零次、一次和多次循环输入检查边界，不要只看正常样例。无符号下标从零递减容易绕回很大的值；循环中修改容器长度会改变边界；嵌套循环的 break 只退出最内层。函数引用参数可能与其他参数指向同一对象，应避免对执行顺序作未经保证的假设。默认参数和重载组合还可能产生歧义，编译器报错时应逐项检查参数类型和候选函数。

## 易错题分析

题210—212：区分 bool、const 和 auto 类型推导。
题213—215：先判断操作数类型，再分析优先级和短路；false && (++x>0) 不改变 x。
题216—218：i<3 对 i=0、1、2 成立，循环3次；continue 仍执行 for 的更新表达式。
题219—221：值传递只改副本；int& 引用参数修改原对象；返回类型不能单独决定重载。

分析值传递和引用传递题，先画出实参对象与形参之间的关系：值形参是独立对象，引用形参是已有对象的别名，再逐句记录赋值后的状态。对循环题列出每次进入循环体时的变量值，而不是只看最终值。对条件表达式先判断是否发生短路，再分析自增等副作用。程序输出题若包含越界、悬空引用或未定义行为，应指出程序本身无可靠结果，而不能猜一个固定输出。
