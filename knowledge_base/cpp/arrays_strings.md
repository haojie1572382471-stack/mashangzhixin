# 数组与字符串

课程：C++
知识点：数组与字符串、指针与引用

来源：码上知新课程知识库

## 核心概念

含 n 个元素的数组使用 0 到 n-1 的下标。访问范围外的元素会导致未定义行为，不能把偶然输出正确当作程序正确。
字符数组保存 C 风格字符串时还需一个末尾空字符。因此 char s[]="abc" 含4个 char，sizeof(s) 为4。
std::string 管理字符串存储，size() 返回字符单元数量，不把末尾终止空字符计入长度。UTF-8 中文常占多个字节，string::size() 不能直接当作汉字个数。
数组在许多表达式中转换为指向首元素的指针；数组本身与指针不是同一种类型。sizeof 原始数组得到整个数组大小，sizeof 指针得到指针本身大小。
引用是对象的别名；指针保存地址，解引用可以访问其指向的有效对象。引用赋值不会重新绑定引用。

选择 std::string 和字符数组时，关注所有权、长度和容量管理。字符数组大小在创建后固定，使用 C 字符串函数必须保证末尾有空字符且目标容量充足；std::string 自动管理空间，支持追加、比较和子串等操作。访问字符串通常使用 0 到 size()-1 的字符位置；at 会对越界访问抛出 out_of_range，不能把 operator[] 当成完整的边界检查。数组长度应与数据一起传给函数，C++17 可用 std::array 表示固定大小容器，用 std::vector 表示动态大小容器。

## 代码示例

下面示例使用 C++17，可独立保存为 .cpp 文件编译运行。assert 检查关键结果；阅读时先预测输出状态，再运行验证。

```cpp
#include <cassert>
#include <string>
int main() {
    int a[4] = {1, 2, 3, 4};
    int& first = a[0];
    first = 10;
    assert(a[0] == 10);
    char text[] = "abc";
    static_assert(sizeof(text) == 4);
    std::string s = "abc";
    s += "de";
    assert(s.size() == 5);
    assert(s.at(4) == 'e'); // at 对非法位置抛出异常
}
```

## 常见错误

访问 a[4] 作为四元素数组的最后一项；把 strlen 的长度与字符数组占用空间混淆；认为函数的 int a[] 形参仍保留数组长度；返回局部数组地址或局部对象引用。

数组函数参数写成 int a[] 时会调整为指针形参，在函数内 sizeof(a) 不能得到调用者的数组总长度。读入带空格的一整行可用 getline，混用流提取运算符时要处理遗留换行符。字符数组没有有效终止符时调用依赖终止符的函数可能继续读到缓冲区外。保存 string::c_str() 的指针后再修改字符串，原指针可能失效；也不能保存临时字符串内部的地址供以后使用。

## 易错题分析

题204、205：引用赋值与有效指针解引用赋值都会修改对应对象。
题222：合法下标是0到3。
题223：std::string 追加 de 后 size 为5。
题224：字符数组 abc 还包含末尾空字符，所以 sizeof 为4，而不是3。

分析字符数组题时分别列出可见字符数、终止空字符和数组容量，三个数字可能不同。分析数组传参题时要区分原数组、首元素指针和数组引用；只有原数组对象仍保留完整大小信息。比较字符串应比较内容，不能用两个字符指针的地址相等来代替文本相等。涉及中文时先确认编码和题目要求的是字节数还是字符数，避免把 ASCII 示例中的长度结论直接推广到 UTF-8 中文。

## 数组下标越界

数组下标越界是指访问不属于数组有效元素范围的位置。例如 int a[3] 的有效下标为0、1、2，读写 a[3] 都越过了数组边界。原生数组的下标运算不会自动检查范围，越界属于未定义行为，可能崩溃、破坏相邻数据，也可能暂时看不出错误。不能根据某次运行输出正确就认为代码安全。循环边界通常应为 i < n，而不是 i <= n。std::vector 的 operator[] 同样要求下标有效；需要运行时检查时可以使用 at()，并处理 out_of_range 异常。
