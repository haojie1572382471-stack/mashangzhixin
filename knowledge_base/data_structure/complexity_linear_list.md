# 时间复杂度、线性表

课程：数据结构
知识点：时间复杂度、线性表

## 核心概念

时间复杂度描述输入规模增长时基本操作次数的增长上界，忽略常数因子和低阶项。独立顺序语句的成本相加，嵌套循环应统计实际执行次数，不能仅凭循环层数判断。
执行 n 次常数操作为 O(n)；每轮把规模减半或把计数翻倍直到 n 通常为 O(log n)；两个独立循环各 n 次的嵌套为 O(n*n)。分析时应说明最坏、平均或摊还情形。
线性表是一对一的逻辑结构，不强制使用连续内存。顺序表使用连续空间，下标访问 O(1)，在表头插入通常需移动 n 个元素，时间为 O(n)。
链表通过指针连接结点，不能直接按下标随机访问。逻辑结构与物理存储结构需要分开理解。

## C++代码示例

```cpp
#include <cassert>
#include <vector>
int main() {
    std::vector<int> a{2, 3, 4};
    int sum = 0;
    for (int value : a) sum += value; // O(n)
    assert(sum == 9);
    a.insert(a.begin(), 1); // 表头插入：移动原有元素
    assert(a[0] == 1 && a.size() == 4);
    int levels = 0;
    for (int size = 16; size > 1; size /= 2) ++levels;
    assert(levels == 4); // 16 -> 8 -> 4 -> 2 -> 1
}
```

## 常见错误

把 O(n) 理解为精确耗时 n 秒；忽略输入规模；把所有双层循环都认作 O(n*n)；把线性表误认为只能用数组实现；把插入操作的地址定位成本与移动成本混淆。

## 易错题分析

题110—112：分别统计 n 次、对数次和 n*n 次基本操作。
题113—115：顺序表按下标访问为 O(1)，表头插入移动 n 项；线性表是一种逻辑关系，不等同于连续存储。
