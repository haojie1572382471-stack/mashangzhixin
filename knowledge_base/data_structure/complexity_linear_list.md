# 时间复杂度、线性表

课程：数据结构
知识点：时间复杂度、线性表

来源：码上知新课程知识库

## 核心概念

时间复杂度描述输入规模增长时基本操作次数的增长上界，忽略常数因子和低阶项。独立顺序语句的成本相加，嵌套循环应统计实际执行次数，不能仅凭循环层数判断。
执行 n 次常数操作为 O(n)；每轮把规模减半或把计数翻倍直到 n 通常为 O(log n)；两个独立循环各 n 次的嵌套为 O(n*n)。分析时应说明最坏、平均或摊还情形。
线性表是一对一的逻辑结构，不强制使用连续内存。顺序表使用连续空间，下标访问 O(1)，在表头插入通常需移动 n 个元素，时间为 O(n)。
链表通过指针连接结点，不能直接按下标随机访问。逻辑结构与物理存储结构需要分开理解。

空间复杂度描述额外存储随输入规模的增长，应说明是否把输入和输出计入。原地扫描数组只保存几个变量，辅助空间为 O(1)；复制 n 个元素通常需要 O(n)；递归还要统计调用栈深度，不能因为没有显式数组就说空间 O(1)。时间复杂度 O(n log n) 常见于把数据分成约 log n 层且每层处理 O(n) 工作的算法，如归并排序；它不是精确操作次数，也不意味着小规模时一定比 O(n*n) 的实现更快。

## 代码示例

下面示例使用 C++17，可独立保存为 .cpp 文件编译运行。assert 检查关键结果；阅读时先预测输出状态，再运行验证。

```cpp
#include <cassert>
#include <vector>
int main() {
    std::vector<int> a{2, 3, 4};
    int sum = 0;
    for (int value : a) sum += value; // O(n)
    assert(sum == 9);
    a.insert(a.begin(), 1); // 表头插入：移动原有元素
    assert(a[0] == 1 && a.size() == 4);
    int levels = 0;
    for (int size = 16; size > 1; size /= 2) ++levels;
    assert(levels == 4); // 16 -> 8 -> 4 -> 2 -> 1
}
```

## 常见错误

把 O(n) 理解为精确耗时 n 秒；忽略输入规模；把所有双层循环都认作 O(n*n)；把线性表误认为只能用数组实现；把插入操作的地址定位成本与移动成本混淆。

顺序表插入时先检查容量和合法位置，再从末尾向后移动元素，若从前向后覆盖就会丢失数据。删除元素后通常把后继前移并减少有效长度，容量不一定随之变化。分析摊还成本时要区分单次操作：vector 末尾插入通常摊还 O(1)，但某次扩容会复制或移动已有元素而达到 O(n)。函数返回大对象、临时容器和递归栈也会占空间，复杂度分析不应只统计源码中可见的变量个数。

## 易错题分析

题110—112：分别统计 n 次、对数次和 n*n 次基本操作。
题113—115：顺序表按下标访问为 O(1)，表头插入移动 n 项；线性表是一种逻辑关系，不等同于连续存储。

分析 O(n log n) 题可以按分治树逐层计数：每层全部子问题合计处理 n 个元素，层数约 log2(n)，相乘得到数量级。分析两层循环时列出内层次数，例如内层固定常数时总计仍为 O(n)。分析顺序表题须分别报告访问、插入和删除，不能把 O(1) 下标访问推广到所有操作。空间题明确统计辅助空间后，再检查数组大小、递归深度和同时存在的临时结果，避免重复计算已经释放的空间。
