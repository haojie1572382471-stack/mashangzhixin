## 核心概念：堆排序的基本过程、排序查找与哈希冲突

普通二分查找要求数据按相同比较规则有序，每轮排除一半候选范围，数组查找时间为 O(log n)。数据可以包含重复元素。
直接插入排序在已经有序、能及时停止后移的情况下为 O(n)，最坏为 O(n*n)。归并排序通常为 O(n log n)，合并遇到相等元素先取左侧可保持稳定性；数组实现通常需要额外缓冲区。
二叉堆是满足堆序的完全二叉树。大根堆父结点不小于孩子，根为最大值；堆不保证所有元素全局有序。二叉堆插入和弹出堆顶最坏 O(log n)，读取堆顶 O(1)。std::priority_queue<int> 默认返回最大值。
哈希冲突是不同键落到同一哈希位置。链地址法用桶关联结构保存冲突项，开放定址法在表内寻找其他位置。分布良好、负载因子受控时平均查找 O(1)，严重冲突时最坏可退化为 O(n)。

堆排序先将数组原地建成大根堆，再把堆顶最大值与当前末尾交换，缩小有效堆范围并向下调整新的根，重复直到有序。自底向上建堆为 O(n)，全部排序为 O(n log n)，典型迭代实现辅助空间 O(1)，但通常不稳定。哈希冲突可用链地址法或开放定址法；开放定址常见线性探测、二次探测等方法，删除时不能简单把槽置为空，否则可能截断其他键的探测路径，需要删除标记或重建策略。

## 代码示例

下面示例使用 C++17，可独立保存为 .cpp 文件编译运行。assert 检查关键结果；阅读时先预测输出状态，再运行验证。

```cpp
#include <algorithm>
#include <cassert>
#include <queue>
#include <unordered_map>
#include <vector>
int main() {
    std::vector<int> values{3, 1, 2};
    std::sort(values.begin(), values.end());
    assert(std::binary_search(values.begin(), values.end(), 2));
    std::priority_queue<int> heap;
    for (int v : values) heap.push(v);
    assert(heap.top() == 3);
    heap.pop();
    assert(heap.top() == 2);
    std::unordered_map<int, int> counts;
    ++counts[7]; ++counts[7];
    assert(counts.at(7) == 2);
}
```

## 常见错误

对无序数组直接二分；将堆数组当成完全排序数组；以为哈希冲突说明算法错误；把平均 O(1) 当成任何输入都 O(1)；误认为 std::sort 保证稳定。

二分查找要统一使用闭区间还是左闭右开区间，更新边界时必须保证区间缩小，否则可能死循环；可用 left+(right-left)/2 避免直接相加溢出。空堆上不能调用 top 或 pop。哈希表扩容可能触发重新散列，使部分迭代器失效；程序不能依赖 unordered_map 的遍历顺序。相等键必须产生一致哈希结果，哈希值相同仍需比较键，不能把哈希碰撞误认为键相等。

## 易错题分析

题119—121：大根堆和默认 priority_queue 的 top 是最大值；插入沿树高调整为 O(log n)。
题125—127：二分需有序；有序输入的直接插入排序可为线性；归并取左侧相等元素可保留相对顺序。
题128—130：冲突需要处理，不能丢弃不同键；受控负载和良好分布下平均查找才接近常数。

堆排序分析应分清当前有效堆与已排好序的后缀，每轮只在有效堆内调整。判断稳定性时给相等元素加原始编号，观察相对次序是否保留。二分边界题用空数组、单元素、全部相等、目标不在范围内等输入验证。哈希表复杂度题必须说明平均与最坏情形，并关注负载因子和分布假设。优先队列只保证能快速取得最高优先级元素，不支持直接把整个内部序列当成有序数组进行二分。
