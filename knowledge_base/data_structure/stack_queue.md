# 栈和队列

课程：数据结构
知识点：栈、队列、后进先出、先进先出、基本操作、应用场景、时间复杂度

## 栈

栈是一种只允许在同一端进行插入和删除操作的线性数据结构。

进行插入和删除的一端称为栈顶，另一端称为栈底。

栈遵循后进先出原则，即 Last In First Out，简称 LIFO。最后进入栈中的元素最先被取出。

## 栈的基本操作

栈的常见操作包括：

1. push：将元素压入栈顶。
2. pop：删除栈顶元素。
3. top：访问栈顶元素。
4. empty：判断栈是否为空。
5. size：获取栈中的元素数量。

调用 pop 或 top 之前，应该先判断栈是否为空。

## 栈的应用场景

栈常用于：

1. 函数调用和递归。
2. 括号匹配。
3. 表达式求值。
4. 浏览器后退。
5. 撤销操作。
6. 深度优先搜索。

## 队列

队列是一种在一端插入元素、在另一端删除元素的线性数据结构。

插入元素的一端称为队尾，删除元素的一端称为队首。

队列遵循先进先出原则，即 First In First Out，简称 FIFO。最先进入队列的元素最先被取出。

## 队列的基本操作

队列的常见操作包括：

1. push：在队尾加入元素。
2. pop：删除队首元素。
3. front：访问队首元素。
4. back：访问队尾元素。
5. empty：判断队列是否为空。
6. size：获取队列中的元素数量。

调用 pop、front 或 back 之前，应该先判断队列是否为空。

## 队列的应用场景

队列常用于：

1. 任务调度。
2. 消息处理。
3. 打印任务管理。
4. 广度优先搜索。
5. 按照到达顺序处理网络请求。
6. 生产者与消费者模型。

## 栈和队列的区别

1. 栈遵循后进先出原则，队列遵循先进先出原则。
2. 栈在同一端进行插入和删除。
3. 队列在队尾插入元素，在队首删除元素。
4. 栈主要访问栈顶元素。
5. 队列主要访问队首元素和队尾元素。
6. 栈常用于递归、回溯和括号匹配。
7. 队列常用于任务调度和广度优先搜索。

## 顺序存储与链式存储

栈和队列都可以使用顺序结构或链式结构实现。

顺序栈通常使用数组或动态数组保存元素，内存连续。

链栈使用链表节点保存元素，扩容更加灵活。

顺序队列直接使用数组时可能出现假溢出问题，通常可以使用循环队列解决。

链队列通过队首指针和队尾指针维护元素。

## 时间复杂度

使用合适的数据结构实现时：

1. 栈的入栈操作通常是 O(1)。
2. 栈的出栈操作通常是 O(1)。
3. 队列的入队操作通常是 O(1)。
4. 队列的出队操作通常是 O(1)。
5. 查看栈顶、队首或队尾元素通常是 O(1)。
6. 遍历全部元素需要 O(n)。

## 递归与调用栈

递归函数在一次调用尚未结束时再次调用自身，后进入的调用必须先返回，符合栈的后进先出顺序。常见实现使用调用栈保存返回位置、参数和局部状态，返回时恢复上一层环境。递归深度过大会占用大量栈空间甚至造成栈溢出。分析空间复杂度时应计入最大同时存在的调用层数。迭代算法可以用显式栈模拟同样的状态恢复过程；某些编译器可以优化特定尾递归，但C++不保证这种优化，不能依赖它消除栈溢出。
